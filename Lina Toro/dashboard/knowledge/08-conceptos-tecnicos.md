# Conceptos técnicos · Glosario para hermosas SAVIAS

Glosario rápido de términos que aparecen en las herramientas y la práctica artesanal.

## Jabonería

| Término | Definición |
|---|---|
| **Saponificación** | Reacción química entre un aceite (triglicérido) y una base (NaOH o KOH) que produce jabón + glicerina natural. |
| **Cold Process (CP)** | Saponificación en frío. Sin aplicar calor durante el proceso. Conserva propiedades naturales. |
| **NaOH** | Hidróxido de sodio (sosa cáustica). Para jabones sólidos. Pureza típica 99%. |
| **KOH** | Hidróxido de potasio. Para jabones líquidos. |
| **Lejía** | Solución de NaOH disuelto en agua. Es lo que se mezcla con los aceites. |
| **SAP (Saponification value)** | Índice de saponificación. Gramos de NaOH puro necesarios para saponificar 1 g de un aceite. Cada aceite tiene su SAP. |
| **SF (Sobreengrasado)** | Porcentaje de aceites que se deja sin reaccionar para aportar suavidad. Default 5%, rango 0–30%. |
| **Concentración de lejía (CONC)** | % de NaOH en la solución con agua. Default 33%, rango óptimo 30–38%. |
| **Traza** | Punto en el que la mezcla aceites+lejía emulsiona y alcanza la consistencia de batido de vainilla. |
| **Curado** | Proceso de reposo del jabón tras desmoldar. Mínimo 4 semanas. Permite evaporar agua y completar la saponificación. |
| **Glicerina** | Subproducto natural de la saponificación (~10.4% del NaOH puro). Es humectante y queda en el jabón. |
| **Surgras** | Jabón con sobreengrasado alto (8–15%). Más suave para pieles delicadas. |

## Ácidos grasos del jabón

| Ácido | Saturado/Insaturado | Rol en el jabón |
|---|---|---|
| Láurico | Saturado | Espuma + limpieza fuerte |
| Mirístico | Saturado | Espuma + dureza |
| Palmítico | Saturado | Dureza + estabilidad |
| Esteárico | Saturado | Dureza máxima + blancura |
| Ricinoleico | Insaturado | Burbujas únicas + cremosidad (solo en ricino) |
| Oléico | Insaturado | Suavidad + humectancia |
| Linoléico | Insaturado | Humectancia + suavidad |
| Linolénico | Insaturado | Humectancia + suavidad |

## Propiedades del jabón

- **Dureza**: estabilidad de la barra al usar. Saturados aportan dureza.
- **Burbujas**: capacidad de espuma. Láurico y mirístico la maximizan.
- **Cremosidad**: cualidad sedosa. Palmítico, esteárico, ricinoleico.
- **Limpieza**: poder desengrasante. >22% reseca la piel.
- **Emoliencia**: suavidad y humectancia. Insaturados.
- **Índice de yodo**: medida de insaturación. <40 muy duro, 50–60 medio (recomendado), >70 muy blanda.

## Cosmética artesanal

| Término | Definición |
|---|---|
| **Emulsión O/W** | Aceite-en-agua. Cremas ligeras, lociones. |
| **Emulsión W/O** | Agua-en-aceite. Más nutritivas, oclusivas. |
| **Anhidro** | Sin agua. No necesita conservante (mantequillas, bálsamos). |
| **Fase acuosa** | Componentes solubles en agua. Calentar a 70–75°C. |
| **Fase oleosa** | Aceites, mantecas, ceras, emulsionantes. Calentar a 70–75°C aparte. |
| **Fase fría** | Activos sensibles, conservante, fragancia. Agregar bajo 40°C. |
| **Emulsionante** | Estabiliza la mezcla aceite-agua. Olivem 1000, BTMS, Emulsifying Wax NF. |
| **Conservante** | Previene contaminación microbiana. Cosgard, Geogard ECT. Obligatorio si hay agua. |
| **Tensoactivo** | Reduce tensión superficial. Limpia. SCI, SLSA. |
| **Activo** | Ingrediente con beneficio específico. Niacinamida, vitamina C, retinol, etc. |
| **Humectante** | Atrae agua a la piel. Glicerina, ácido hialurónico, urea. |
| **Emoliente** | Suaviza y lubrica. Aceites, mantecas. |
| **Oclusivo** | Forma película protectora. Cera, manteca de karité. |
| **Astringente** | Tonifica, contrae. Hamamelis. |
| **pH** | Potencial de hidrógeno. Piel sana 5.0–5.5. Medir con tiras o pHmetro. |

## Extractos botánicos

| Término | Definición |
|---|---|
| **Oleato** | Planta macerada en aceite. Conserva activos liposolubles. 21 días. |
| **Glicerinado** | Planta en glicerina vegetal + agua (1:1). Humectante. 14–21 días. |
| **Infusión acuosa** | Planta en agua hervida. Activos hidrosolubles. **Caduca rápido** (3 días en nevera). |
| **Tintura hidroalcohólica** | Planta en alcohol etílico 70°. Máxima extracción. 14–21 días. |
| **Maceración** | Reposo de planta en solvente durante días/semanas. |
| **Filtrar** | Separar la planta del extracto con gasa, lienzo, café, papel filtro. |

## Activos estrella más usados

- **Niacinamida** (vitamina B3): regula sebo, reduce poros, calma. 2–10%.
- **Vitamina C** (ácido ascórbico): antioxidante, ilumina, despigmenta. 5–20%. Sensible a luz y aire.
- **Ácido hialurónico**: humectante poderoso. 0.5–2%. Nunca calentar.
- **Retinol / Bakuchiol**: anti-edad, renovación celular. Bakuchiol es alternativa natural.
- **Pantenol** (provitamina B5): humectante, calmante. 1–5%.
- **Centella asiática**: regenerante, calmante. Para sensibles, rosácea.
- **Caléndula**: cicatrizante, antiinflamatorio. Para eczema, dermatitis.
- **Manzanilla**: calmante, antiinflamatorio. Para sensibles.
- **Árbol de té**: antibacteriano. Para acné. Máx 1% en cosmética leave-on.
- **Romero**: antioxidante, estimulante. Para cabello y anti-edad.
- **Ceramidas**: reparan barrera cutánea. Para secas y dañadas.
- **Escualano**: emoliente ligero, no comedogénico. Universal.

## Equivalencias rápidas en formulación

- 1% = 1 g cada 100 g de lote
- 0.1% = 1 g cada 1000 g de lote
- 5% en lote 250 g = 12.5 g

## Seguridad

- **EPP siempre con NaOH**: guantes, gafas, mascarilla, ropa cubierta, zona ventilada.
- **NaOH al agua, nunca al revés** (puede explotar).
- **Prueba de parche** obligatoria antes de usar cualquier nuevo producto en cara o cuerpo.
- **No es consejo médico**: para condiciones diagnosticadas, dermatólogo.
- **Embarazadas y niños**: extra precaución con AAEE, retinol, ácidos potentes.
- **Aceites esenciales**: máximo 2% en cosmética leave-on, aunque la mayoría indique 5%.
